Read this before you commit a design

IPC-2221 is an empirical model from measured boards, not a field solver. It ignores copper planes, thermal reliefs, adjacent traces and airflow. For anything carrying real power, treat the result as a floor: add margin, run a thermal test on the actual board, and check your fabricator's minimum trace and space.
