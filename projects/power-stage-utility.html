Power-stage sizing utility.

A small calculation module that turns a converter specification into an inductor, a capacitor and a current-stress estimate — with the formulas, assumptions and test cases published alongside it.

Values update as you type. Defaults are the site's reference operating point.

01 / WHAT IT COMPUTES

From a specification to component values.

The module takes the input range, output voltage, load current, switching frequency and two ripple targets, then returns the inductance needed to hold the ripple target at the worst-case duty point, the resulting peak and valley currents, the RMS current that heats the winding, and the ideal output capacitance for the voltage-ripple target.

  • Worst case for inductor ripple is the lowest input voltage, because duty — and therefore the off-time — is longest there.
  • Peak current sets the saturation requirement; RMS current sets the heating requirement. They are different numbers and both matter.
  • The capacitor estimate uses the ideal ΔV ≈ ΔI/(8 f C) relation for a resistive load.
02 / WHAT IT DOES NOT DO

Deliberate limits.

  • No switch, diode or inductor resistance — a real converter needs more duty than this predicts.
  • No ESR, so the capacitor figure omits the ripple term that often dominates.
  • No thermal model, no loop stability, no transient response, no dead time, no saturation derating.
  • Steady-state CCM only. Ripple is defined relative to load current here, so a 100 % target still leaves a valley of Iout/2; the reported CCM boundary inductance is the honest indicator.
